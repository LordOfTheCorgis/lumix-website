# Where these came from

Pulled 2026-09-11. Each is the publisher's own mark, used the way every game
host uses them: to identify the game being hosted. Cropped to the artwork,
shrunk to 112px tall (2x of the 56px they render at), webp at q88 or SVG with
the metadata stripped. Black-on-transparent originals got `fill="#f7f5f1"`.

| file | source |
|---|---|
| minecraft.svg | Wikimedia Commons, File:Minecraft Logo-en.svg |
| fivem.webp | Wikimedia Commons, File:FiveM-Logo.png |
| rust.svg | Wikimedia Commons, File:Rust vector logo.svg |
| arma-reforger.svg | Wikimedia Commons, File:Arma Reforger Logo (Black Transparent).svg, recoloured |
| terraria.webp | terraria.org/TerrariaLogoOG.png |
| squad.webp | joinsquad.com, squadlogo_white_gold_hires.png |
| ark-survival-ascended.webp | survivetheark.com, ASA_Logo_512x512.png |
| beammp.webp | beammp.com/assets/BeamMP_blk.png, black recoloured to paper |
| palworld.svg | logosarchive.com/logo/palworld, recoloured to paper |

If a publisher ever asks for theirs to come down, delete the file and the
build fails on the yaml `logo:` line, which is the point.
